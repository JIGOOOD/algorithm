## 💡 접근 및 설계

냅색임. 근데 그룹 냅색.

    // 이것은 원래 냅색
    // dp[i][w] = 최대 w학점일 때, i까지 봤을 때의 최대 선호도 값

    for(int i=1; i<=n; i++){
        int p, c;
        tie(p, c) = a[i];
        for(int w=1; w<=m; w++){
            if(w < c) dp[i][w] = dp[i-1][w];
            else dp[i][w] = max(dp[i-1][w], dp[i-1][w-c] + p);
        }
    }

해당 문제는 하나의 기업마다 하나의 금액을 골라야 함.

원래는 그냥 쫙 가방이 나열되어있고 그 중 고르든 말든 하는거임.

그래서 기업이 돈을 고르는 레이어가 하나 추가됨.

    for(int i=1; i<=m; i++){ // 기업
        for(int j=0; j<=n; j++){ // 전체 돈
            for(int k=0; k<=j; k++){ // 기업 돈
                int v = dp[i-1][j-k] + w[i][k];
                if(dp[i][j] < v){
                    dp[i][j] = v;
                    ch[i][j] = k; // 당시 기업 i가 고른 금액 수
                }
            }
        }
    }

이후에 기업이 얼마를 지불했는지를 출력하기 위해 역추적 배열 ch도 둬야 함.
