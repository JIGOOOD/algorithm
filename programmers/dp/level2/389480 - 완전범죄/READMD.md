### **✏️ 알고리즘 풀이**

각 물건을 A가 훔칠지 B가 훔칠지 판단하는 냅색 문제이다.

그런데 A는 n개 이상을 훔칠 수 없고, B는 m개 이상을 훔칠 수 없다. 이 상태에서 A 흔적의 최솟값을 구해야 한다.

1. **dp 정의**

   그래서 dp를 이렇게 정의한다.
   - dp[i][j]: i번째 물건까지 처리했을 때, b흔적이 j인 상태에서 a흔적의 최솟값.
   - i를 인덱스가 아니라 물건으로 둔 이유는 누적합을 구하기 위해 1-indexed로 만들기 위함이다.
   - a 흔적의 최솟값을 구하는 것이므로 dp는 초기값을 max 값으로 정하고, dp[0][0]만 0으로 초기화한다.

2. **dp 채우기**

   ```cpp
   int l = info.size();
       for(int i=1; i<=l; i++){ // i = 물건 처리 개수 (1-indexed로 만들기 위함)
           int a = info[i-1][0];
           int b = info[i-1][1];
           for(int j=0; j<m; j++){ // b 흔적 개수
               if(j < b) dp[i][j] = dp[i-1][j] + a; // a를 고름
               else dp[i][j] = min(dp[i-1][j] + a, dp[i-1][j-b]); // 각각 a고름, b고름
           }
       }
   ```

3. **최솟값 구하기**

   l물건까지 모두 처리한 상태에서, b흔적이 0~m-1인 값 중 최솟값을 구한다.

   하지만 처음 조건에서 a흔적은 n값을 넘지 않아야 한다는 것이 있으므로 이를 반영해서 구한다.

   ```cpp
   int mn = mx;
   for(int i=0; i<m; i++){
       if(dp[l][i] < n) mn = min(mn, dp[l][i]);
   }

   if(mn == mx) return -1;
   else return mn;
   ```
